\# Synthetic Dataset Specification



\*\*Owner:\*\* Koundinya

\---



\# 1. Purpose



Defines the requirements for generating synthetic insurance data for

development, testing, analytics and ML experimentation.



\---



\# 2. Dataset Entities



The generator should produce records for:



\- customers

\- policy\_types

\- policies

\- policy\_coverages

\- claims

\- claim\_events



Risk scores should initially be generated by the ML pipeline rather

than being treated as ground-truth source data.



\---



\# 3. Initial Dataset Scale



The dataset generator should support configurable record counts.



Example development configuration:



```text

customers: configurable

policies: configurable

claims: configurable

coverages: configurable

claim\_events: configurable
